# Smart Traffic Congestion and Signal Management System

1. In the VS Code terminal, inside this folder: `gcc main.c -o traffic -lm`
2. Run it: `./traffic` (Windows: `traffic.exe`). It prints a results table and writes `data.js`.
3. Open `index.html` (double-click, or right-click > Open with Live Server). Click **Start simulation**.

Files: `queue.h` circular queue, `heap.h` min-heap, `main.c` scheduler/metrics/output, `index.html` viewer.
Re-run the C program any time you change parameters (rates, green times) in `main.c`.
